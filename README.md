# Dispatch Message Builder

A standalone static page for composing professional WhatsApp dispatch updates and keeping order records.

## Publish with GitHub Pages

Upload `index.html`, `records.html`, and `README.md` to the repository root. In **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save. GitHub will display the published website URL on that settings page.

Dispatch records are stored in the visitor's browser and shared between the two pages on the same site. The records page can also save individual JSON files to a selected folder. Excel export is a CSV file that opens in Excel. PDF export opens a print view where the user can choose Save as PDF. Report exports do not include WhatsApp message text.
